### Notes

Largest gap since `eb267fe`. Shell jumped `1.0.3` → `1.0.16`. Most of the diff is TUI/pager, sandbox, telemetry, bot-relay, and dead-code deletion. PinkCode-relevant protocol/lifecycle:

**ACP session bootstrap.** Effort now belongs on `session/new` and `session/load` as `_meta.reasoningEffort` (PinkCode still sends it only on `session/set_model`). `session/new` is answered at spawn (empty catalog still fills via `models/update`). New method: `session/set_config_option`. Bind-time MCP servers can ride the create call.

**Models.** Catalog grows optional `model_family` (compact on family switch). Effort is a setting, not N model slugs; a model may advertise a different id per effort. Selectable models can be pinned from signed `requirements.toml`. Last-used effort should survive `/new` and `/clear`.

**MCP elicitation.** First a HITL popup, then MCP 2026-07-28 multi round-trip. Desktop has no elicitation surface today. Stdio MCP no longer blocks session startup; OAuth moved off spawn; merge/discovery keyed by server name.

**Consent.** Remote settings can carry a consent notice; session stays blocked until accepted. Acceptances are recorded server-side.

**Hooks.** UserPromptSubmit can block and hold the queue (before chat-state commit). PreToolUse parses `additionalContext` / defer and can ask the user. PostToolUse client hooks contribute feedback. Hook-denied turns must not look like user-cancel. Managed-policy hooks cannot be disabled.

**Turns / subagents.** Don't cancel a live parent-message turn. Keep a running command alive on send. Wait for a spawning child before send fails; steer owned subagents at the next safe point; follow-up messaging; never treat spawn as a plan-mode file edit; drop spawn-time `capability_mode`; keep ask-user out of children; always shut down completed child sessions even if parent is busy; evict finished transcripts. Concurrent sampling is gated; 429 backoff on child turns.

**Compaction / length.** Default two-pass + segments. Salvage length-truncated responses (remote-gated); execute completed tool calls on Length-truncated turns. Re-inject scheduled loops and live workflows on compaction. 413 / size-overflow go through the compaction input ladder. `get-output` waits capped at 1h.

**Permissions.** Pre-session permission mode. `remember_tool_approvals` defaults on; persistent Never-allow for MCP tools and web-fetch domains. Interactive default permission mode is configurable (auto was briefly the TUI default, then reverted). Headless always-allow so it never wedges. Trusting a parent dir no longer implicitly trusts later clones under it.

**Security (agent-side).** Symlink Write/Edit deny bypass; `GROK_CHANNEL` RCE into `config.toml`; SessionStart hook persistence escaping sandbox; installer deployment-key Bearer to attacker URL; parent-dir trust; `io_uring` child-network bypass.

**Mostly TUI / internal.** Status line, gated panel dock, pager compression, gboom extract, bot-relay skeleton, profiler spans, settings cache-first boot, Windows CLI zstd/gzip.
